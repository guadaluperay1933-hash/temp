# 内帐系统 · 目录结构

| 目录 | 放什么 |
|---|---|
| `00-总账/` | 内帐总账工作簿。**唯一录入口**，全公司业务 + 项目维度都在这里录。 |
| `项目-XMxxx-项目名/` | 每个工程项目一个文件夹。 |
| `项目-XMxxx-项目名/原始单据/` | 该项目的合同、验工单、结算单、发票、付款凭证扫描件。 |
| `90-公共与分摊/` | 不能直接归集到单个项目的公共费用，及其分摊计算表。 |
| `99-归档模板/` | 原始模板与空白分账簿模板，不要在这里录数据。 |

## 每月流程

1. 在 `00-总账/` 的总账工作簿里录三张表：资金流水、销售录入（工程结算）、采购录入。
   每笔都要选【项目】；指不到具体项目的（房租、管理人员工资）选「公共」。
2. 月末在总账的【公共费用分摊】页确认分摊比例，公共费用自动分到各项目。
3. 在【项目分账簿】页选中某个项目，另存为该项目文件夹下的分账簿，发给项目经理。
4. 原始单据按项目归入对应文件夹的 `原始单据/`。

## 命名约定

- 项目文件夹：`项目-项目编号-项目简称`，编号与总账【基础资料·项目档案】里的项目编号一致。
- 分账簿：`项目分账簿_项目编号_年份.xlsx`
- 单据：`日期_单据类型_摘要.pdf`，如 `20260612_验工单_一标段6月产值.pdf`
