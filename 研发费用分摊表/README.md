# 研发费用工时分配与费用分摊表（设计说明）

适用场景：研发费用归集、研发支出辅助账、高企认定与研发费用加计扣除备查资料。

## 一、两个文件、两条职责

| 文件 | 使用部门 | 职责 |
|---|---|---|
| `2026年研发工时分配表（研发部填报）.xlsx` | 研发部 | **只填工时，不出现任何金额**（工资保密） |
| `2026年研发费用分摊表（财务）.xlsx` | 财务部 | 维护费用标准 → 按工时比例分摊 → 月度/年度汇总 |

工资、社保、公积金、折旧额、摊销额全部放在财务文件的【参数设置】页，研发部拿到的表里看不到钱。
这也是把原表里那几列"月费用标准"从研发填报表中移出来的原因。

## 二、研发部填报表（文件一）

| 工作表 | 用途 |
|---|---|
| 说明与项目清单 | 填表规则 + 项目编号/名称（各表表头自动引用，最多 8 个项目） |
| 人员工时月报 / 设备工时月报 / 无形资产工时月报 | 每月填写、打印、签字存档的正式表单 |
| 人员工时年度台账 / 设备工时年度台账 / 无形资产工时年度台账 | 月报签字后追加录入，**这三张表就是提交给财务的数据** |

三张月报的结构与原表一致，改动如下：

1. 删除原表右侧的"费用标准"列（工资/社保/公积金/其他、折旧费用、摊销费用）——移交财务。
2. 项目列扩到 8 个（RD01–RD08），表头从【项目清单】自动引用，改项目名只需改一处。
3. 新增【校验】列：某人/某设备分到各项目的工时合计大于当月总工时时报警。
4. 年度台账加了【月份】列（1–12 数字）并做了数据有效性限制，便于财务按月取数。

**非研发活动工时 = 当月总工时 − 各项目工时合计**，由公式自动算，不手填。
这一列是把费用先在"研发 / 非研发"之间切开的依据，研发部分再细分到各项目。

## 三、财务费用分摊表（文件二）

| 工作表 | 说明 |
|---|---|
| 说明 | 每月 5 步操作 + 分摊公式 + 数据流向 |
| 参数设置 | 项目清单、人员月费用标准、设备月折旧额、无形资产月摊销额、费用项目清单 |
| 01人员工时 / 03设备工时 / 05无形资产工时 | **粘贴区**，列序与研发部年度台账完全一致，整块选择性粘贴为"数值"即可 |
| 02人员费用分摊 | 每人每月固定 4 行（工资/社保/公积金/其他），全部公式生成 |
| 04设备折旧分摊 | 设备编号、设备名称、月折旧额 → 非研发承担 + 各项目分摊 |
| 06无形资产摊销分摊 | 同上 |
| 07月度汇总 | 12 个月 × (人员人工/折旧/摊销/小计) × 各项目 |
| 08年度汇总 | 按费用类别汇总 + 各项目分月汇总，可直接过研发支出辅助账 |

### 分摊公式

```
某项目分摊额 = 当月费用总额 × 该项目当月工时 ÷ 当月总工时
非研发承担额 = 当月费用总额 − 研发各项目分摊额合计      （尾差计入非研发）
```

所以每一行恒等式成立：**非研发承担 + 各项目分摊合计 = 合计 = 费用总额**，【校验】列自动核对。

### 勾稽链条

```
研发部月报（签字存档）
   ↓ 追加录入
研发部年度台账
   ↓ 选择性粘贴-数值
财务 01/03/05 工时页
   ↓ 公式自动分摊（02 按 INDEX 按行对应，04/06 按行一一对应）
财务 02/04/06 分摊页
   ↓ SUMIFS 按月份汇总
07 月度汇总 → 08 年度汇总 → 研发支出辅助账
```

- **02人员费用分摊**：第 7 行起每 4 行对应工时表的 1 行人员，月份、姓名由公式从【01人员工时】按行取，
  费用项目按【参数设置】的顺序循环，金额按"姓名 + 费用项目"从费用标准表 INDEX/MATCH 取。
  研发部工时一改，分摊金额自动跟着变，不存在两头对不上的情况。
- **04/06**：分摊表第 N 行 = 工时表第 N 行，设备编号、名称、工时全部引用工时页，月折旧额按设备编号取参数。

### 当月实际金额与标准不一致

调薪、入离职、年终奖、新增/处置设备、折旧提完等情况，不要去改公式：
在分摊表最右侧【本月实际金额（覆盖）】列填入实际数即可，该列留空时才走参数设置的标准。

## 四、颜色与扩行

- 黄色底纹 = 手工录入；黑色字 = 本表公式；绿色字 = 引用其他表的公式，勿覆盖。
- 行数不够：选中最后一行整行复制向下粘贴。人员分摊表须按 **4 行一组** 整组复制。
- 07/08 汇总表的取数范围已预留到第 1000 行，扩行后不用改汇总公式。

## 五、本表不覆盖的费用

本套表只解决**按工时分摊**的三类费用：人员人工费用、折旧费用、无形资产摊销费用。
直接投入费用（材料、燃料动力、试制检验费）按领用单据直接归集到项目；
委托外部研发、新产品设计费、其他相关费用单独归集（其他相关费用不得超过可加计扣除研发费用总额的 10%）。

## 六、示例数据

两个文件都预置了 2026 年 9 月的示例数据（张三…陈七、设备 046…081、无形资产 Z0001…Z0006，
月折旧/摊销额均按 1200 元示意），**正式启用前请清空**，相关单元格【备注】列已标注。
