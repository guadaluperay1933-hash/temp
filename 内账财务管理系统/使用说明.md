# 内账财务管理系统 · 通用版

一套开箱即用的 Excel 内账（管理账）系统，适用于贸易、零售、服务、加工等各类中小企业。
只录四张表，总账与全部报表自动生成。

## 文件

| 文件 | 说明 |
|---|---|
| `内账财务管理系统_通用版.xlsx` | 主文件。内含 2026 年 1 月的完整演示数据，正式使用前清空即可 |
| `参考/原始模板_2026.8.19.xlsx` | 重构前的原始模板，仅作存档 |

## 25 张表

**入口**：首页（仪表盘）· 操作说明

**配置**：科目参数（会计科目 + 收支科目）· 基础资料（账户/部门/员工/商品/客户/供应商）· 期初数据

**录入（只有这四张要手工填）**：资金流水 · 销售录入 · 采购录入 · 其他凭证

**总账报表**：科目余额表 · 科目分析 · 利润表 · 资产负债表 · 现金流量表

**业务辅助**：账户余额 · 库存收发存 · 应收跟进 · 应付跟进 · 固定资产台账 · 工资表 · 辅助核算 · 客户对账单 · 供应商对账单 · 经营分析

**月结**：财务勾稽核查（16 项跨表比对）

## 核心设计

**每行业务自带分录对。** 每一行录入都会自动算出借方科目、贷方科目和金额，一行同时贡献一借一贷。所以借贷是**结构性相等**，不可能出现单边挂账。

**没有任何写死的科目清单和年份。** 科目表随便加，年度在首页改一格，所有报表自动跟随。科目余额表以「期间 + 科目」为键统一 SUMIFS 汇总。

**全部使用 Excel 2007 就有的函数。** 没有 FILTER / XLOOKUP / TEXTJOIN 等动态数组函数，WPS 个人版、Excel 2016 都能正常打开和重算。

## 快速开始

1. **改首页两格**：会计年度、查询月份。
2. **配收支科目**（`科目参数` 第二区）：每条配好「对方科目」——这笔钱的另一半。这是适配不同行业的主要工作，比如餐饮加「食材采购」、电商加「平台佣金」。
3. **建档案**（`基础资料`）：账户、部门、员工、商品、客户、供应商。
4. **录期初**（`期初数据`）：启用日的资产、负债、所有者权益余额。⑤会计科目期初必须借贷相等。
5. **查 `财务勾稽核查` 第 2～7 项全部 ✓**，再开始日常录入。

## 每月流程

| 时点 | 做什么 | 在哪 |
|---|---|---|
| 平时 | 收付款 | 资金流水 |
| 平时 | 卖出 | 销售录入 |
| 平时 | 买入 | 采购录入 |
| 月末 | 工资/社保/折旧/摊销/税金计提 | 其他凭证 |
| 月末 | 首页切到本月 → 勾稽核查全 ✓ → 打印报表 | 财务勾稽核查 |
| 年末 | 结转损益 | 其他凭证 |

## 关键口径

- **销售成本**：按「期初 + 该笔销售日期之前的入库」计算移动加权平均单价。无采购记录时退回商品档案的参考成本。
- **库存金额**：期初金额 + 采购金额 − 结转成本，与科目余额表的「库存商品」永远一致。
- **账龄分桶**：按到期日累计应收额减累计回款，等价于回款先冲抵最早的单据（FIFO）。
- **未分配利润**：利润分配类科目余额 + 利润表本年净利润。年末做了结转损益也不会重复计算。
- **现金流量表**：直接法，按收支科目自动归类；账户间内部转账不计入。
- **年中启用**：期初只录资产负债权益，本年已发生的收入费用到「其他凭证」按月补录（业务类型选「年初建账」）。损益类科目不要录期初。

## 颜色约定

| 颜色 | 含义 |
|---|---|
| 淡黄底 | 手工录入区 |
| 白 / 灰底 | 公式自动计算，请勿覆盖 |
| 绿色字 | 引用其他工作表的公式 |
| 红底 | 校验未通过，必须处理 |

工作表标签也按功能分色：深蓝＝入口，灰＝配置，橙＝录入，绿＝总账报表，蓝＝业务辅助，红＝月结检查。

## 容量

资金流水 500 行 · 销售 400 行 · 采购 400 行 · 其他凭证 300 行 · 会计科目 120 个 · 商品 200 · 客户/供应商各 150 · 员工 60 · 固定资产 100。

不够时在数据区**中间插入整行**再复制公式，不要在最后一行下面直接粘贴（会盖掉合计行）。

## 注意

- 基础资料、期初数据是横向分区共用行号，**删整行会同时删掉旁边几个区的数据**。清空请选中单元格按 Delete。
- 停用档案请把「状态」改成停用，不要删。
- 年内不要做结转损益，损益科目余额本身就是本年利润，资产负债表已经自动接住。
