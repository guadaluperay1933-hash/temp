### 三张子表怎么自动拆的

跟资金台账的账户分表**一模一样的做法**：每张子表的 A4 是一条 FILTER，

```
=FILTER(表2客户典当登记!$A$4:$X$403, 表2客户典当登记!$B$4:$B$403=$B$2, "这个机构还没有记录")
```

`$B$2` 就是这张表自己的机构名字。在表2登记完，三张子表立刻跟着变。

子表整块是**一条公式的结果**，别在里面打字（会把公式顶掉）。要改数据去表2改。

**再加一个机构**：① 在【资料】A 列加名字；② 复制一张子表，把 B2 改成新名字。完事。

每张子表右边（AA:AL 那几格）自带小汇总：笔数、典当金额、已还本金、当前在当、应收利息。

## 二、查询表怎么用

1. **两个文件都要打开**
2. B3 那格选客户姓名
3. 上面汇总条 + 下面三块明细全部自动跳出来

| 位置 | 内容 | 来源 |
|---|---|---|
| 第 5 行 | 汇总条：典当笔数/金额/已还/在当/应收利息、不动产笔数/金额、资金收到/付出 | 三处合算 |
| 第 8 行起 | 一、典当记录（40 行位） | 表2 |
| 第 52 行起 | 二、不动产记录（20 行位） | 表1 |

> **为什么必须两个都打开**：FILTER、SUMIF 这类公式读不了「关着的」工作簿，这是 Excel 的规矩，

每块右边有个提醒：万一某个客户的记录超过预留行数会显示 `※记录超过预留的 N 行`，看到就告诉我加行。

## 三、⚠ 一件查出来的事：表1 和表2 的金辉典当是同一批当

逐条比对过：

```
表1 共 67 行；表2 里「抵押机构=金辉典当」也是 67 行
按 姓名+典当金额+当票号 三项比对，66 行完全一致
```

也就是说 **表1 不是另外一批业务**，它是那 67 笔金辉当的"收款明细版"——
多出来的是 对公 / 林总 / 建行民生 / 微信 的收款拆分、违约金、滞纳金、实际付息日。

**所以两张表的金额千万不能相加。** 查询表里也是分两块单独列的，就是这个原因，
第二块的标题上写了「别跟上面相加」。

你说「表1和表2还是单独分开」，我照做了，没合并，只是把这个重叠关系标出来免得以后算重。

## 四、这次改了什么

### 表2（原 Sheet2，201 行全部搬过来）

- 「个人借款」统一改名 **「个人典当」**（134 笔），跟子表名字对上；金辉典当 67 笔
- 新增 **身份证号**、**客户电话** 两列（空着，你自己补）—— 查询表按姓名查，身份证号自动带出来
- 新增 **当前在当** 列 = 典当金额 − 已还本金，自动算
- 新增 **核对** 列，逐行挑毛病：机构/状态不在名单、已还本金大于典当金额、到期日早于当票日期、当票号重复、有金额没写客户
- 列顺序理了一遍：查询要用的都挪到前 18 列，这样 FILTER 一次能整块取走
- 「应收金额」改叫 **「应收利息」**，意思没变
- 「典当系统」改叫 **「典当系统费率」**

### 表1（原 Sheet1，67 行全部搬过来）

- 新增 **合计收款** = 对公+林总+建行民生+微信+违约金，自动算
- **逾期天数** 改用日期相减，不再用 DATEDIF ——
  原来有一行（施鉴波，实际付息日 8-21 早于应付息日 8-22）会让 DATEDIF 直接报 `#VALUE!`，
  外面套 MAX 也救不回来。现在这种情况算 0 天
- **应收滞纳金** = 典当金额 × 日滞纳金率 × 逾期天数 − 已收违约金；
  日滞纳金率搬到【资料】L4 那格（原来是 0.001），改一处全表跟着变
- 新增 **核对** 列

### 关于「利息对不对」这个检查，我做了又拿掉了

原本加了「应收利息 应该 = 金额 × 费率」的自动核对，一跑 67 行里有 18 行报警。
翻了一下：

```
郑大可  金额 40,000  费率0.025  利息 1,500   实际比值 0.0375
吴灵铭  金额150,000  费率0.01   利息 3,750   实际比值 0.0250
廖浴波  金额 35,000  费率0.003  利息   800   实际比值 0.0229
```

费率这一列各行口径不一样（有的按月、有的按日、有的是别的算法），拿它反推利息只会整屏报警，
全是噪音。所以这条检查去掉了 —— 宁可不查，也不给你一堆假警报。要核利息直接看「应收利息」那列。

现在两张表各自只剩 **2 条**真提示（都是「到期日早于当票日期」，原表数据本来就是这样）。
