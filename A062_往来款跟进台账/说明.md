# A062 多账户收支台账 · 这次改了什么

> 你的要求：**「往来款跟进要增加相应公式 —— 录入客户销售产品的金额、销售费用（赠送券）、
> 和供应商购货款，然后提取数据录入界面相关数据，自动得出应收款、尚欠款。」**

---

## 一句话

**淡黄色的格子你填，淡灰色的格子全自动。**
「已收款」「已付款」现在从【数据录入】自动认领，应收款、尚欠款、未收总计一路自动算出来。

---

## ① 你现在只需要填这几格

【往来款跟进】第 11 行往下：

| 填什么 | 在哪一列 | 说明 |
|---|---|---|
| 日期 | B | |
| 客户生日 | C | 现在显示成「4月1日」，不再是 46113 那种裸数字 |
| **客户名称** | D | **有下拉了**，从【基础资料】的客户清单里选 |
| **销售产品** | E | **有下拉了**，从【基础资料】的产品清单里选 |
| **销售金额** | F | ← 你要录的 |
| **销售费用（赠送券）** | J | ← 你要录的 |
| 支付方式 | K | **有下拉了** |
| 备注 | L | |
| 日期 / **供货商** / **购货款** | M / N / O | ← 右边应付那块，供货商也有下拉 |

**剩下的一格都不用填**：已收款、尚欠款、未收总计、已付款、尚欠款总计，全部自动。

---

## ② 「已收款」是怎么自动出来的

在【数据录入】里按日常习惯记流水的时候，**把「客户」那一列选上**，
【往来款跟进】这边就会自动认领这笔钱。供应商付款同理，选「供应商」那一列。

**同一个客户买了好几笔的，按先买的先冲：**

> 沈祖模买了两笔：羊奶 3,280、乳铁 3,980，一共 7,260。
> 他付了 5,000 → 第一笔收满 **3,280**，第二笔认 **1,720**，还欠 **2,260**。

### 有个前提你得知道

【数据录入】里「客户」那一列**目前只有 1 行填了值**（第 19 行 丁爱妹），
「供应商」也只有 1 行。也就是说你现在这 7 行销售、19,140 元的回款，
在【数据录入】里根本没有对应的记录。

所以公式做了**兜底**：

> 【数据录入】里还没记到某个客户的回款时，「已收款」**沿用你原来手工填的那个数**
> （原值存在隐藏的 T 列，一分没丢）。等你开始在数据录入里逐笔选客户名，它就自动接管。

最右边的 **AA「核对」列**会告诉你每一行现在是哪种状态：

- `√` —— 没问题
- `用的还是原手工已收款` —— 数据录入里还没记这个客户的回款
- `自动算的已收款和原手工数对不上` —— 两边都有数但对不上，要查
- `客户名不在基础资料里` / `产品名不在基础资料里` / `供货商不在基础资料里`
- `销售费用大于销售金额` / `客户生日填得不对（不是日期）`

核对列一旦不是 `√`，**整行会自动标红**。

## ③ 新增一张表：【客户供应商往来对账】

全自动，一格都不用填。

**上半段按客户一行**：销售金额 / 销售费用 / 应收款 / 已收款(往来款跟进) / 已收款(数据录入) / **尚欠款** / **差额** / 提示
**中间按供货商一行**：购货款 / 应付款 / 已付款两个来源 / 尚欠款 / 差额 / 提示

差额 ≠ 0 的行会标红，提示会直接写明白：
「差 1,640.00 元：【数据录入】里这个客户的回款还没记全，或者没选客户名」。

客户和供货商的名单**直接跟着【基础资料】走** —— 你在基础资料里加一个客户，这里自动多一行。

**最下面还有一块红色的「还没挂到人头上的钱」**：

| | 金额 |
|---|---|
| 收进来但没选客户名的钱 | **20,200.00** |
| 付出去但没选供应商的钱（支出类别已选「供应商」） | **1,000.00** |
| 【数据录入】收入合计 | 22,200.00 |
| 【数据录入】支出合计 | 11,660.00 |

这部分【往来款跟进】永远认领不到，得回【数据录入】把人头补选上。
（那 1,000 元就是原表第 32 行：支出类别选了「供应商」，但供应商那一列忘了填。）

## ④ 顺手修掉的几处算错的公式

这些不是我加的功能，是原表本来就错的，不修的话新公式也算不对：

| 位置 | 原来 | 问题 | 现在 |
|---|---|---|---|
| **H 尚欠款** | `=销售金额−已收款` | **漏了销售费用**。谢爱琴那两行各送 300 元券，算出来是 300，所以原作者只好把 H13/H14 手敲成 0 盖掉 | `=销售金额−已收款−销售费用`，两行自然回到 0 |
| H18:H47 | 整段 30 格公式被删空 | 你在这几行补录销售，尚欠款不会自己算 | 铺满到 510 行 |
| **I 未收总计** | 一环扣一环的累计，I47 断了 | 表尾从 3,920 **崩成 0**；而且 18~46 行没业务也照样印 3,920 | 改成直接对 H 列求和，中间空一行也断不了 |
| R 尚欠款总计 | 同上 | 同上 | 同上 |
| **S3 / S4** | `SUMIFS(...,N列,S2)`，而 S2 里放的是**表头文字「供货商2」** | 拿标题去匹配供货商名，永远匹配不上 —— 购货款/已付款/尚欠款**恒为 0** | 直接汇总全部供货商 |
| 汇总块区间 | F11:F2001 / J11:J1001 / 11:2000 / 11:1000 **四套并存**，而行内公式只到 501 行 | 口径不一致 | 全部统一到 11:510 |
| M2 / M3 | `SUMIF(...,">0")` | 会**静默丢掉负数**（退货、红冲） | 改成 SUM |
| **A 序号** | 残留的数组公式 `=ROW(2:500)` | 和 A12 起的硬写数字打架，而且**从 2 开始编号** | 跳过空行的计数式，从 1 开始 |
| 整表 | 一条数据验证都没有 | 所以才录得进「乳铁蛋白」（基础资料里叫**乳铁**）和 4 个一格塞两个人名的格子 | 4 列加了下拉 |

### 还有【数据录入】一个会闷声出错的坑

> **H 列「账户余额」的公式只铺到第 100 行**，A 列序号只到第 249 行。
> 你录到第 101 笔流水，账户余额就直接空白了，而且不会报错。

都补到第 4999 行了，和【客户供应商汇总】取数的区间对齐。

## ⑤ 需要你自己处理的 5 处数据问题

系统标出来了，但得你来定怎么改：

1. **4 格塞了两个人名**（中间是换行）：
   `邬香花/方建宏`(D22)、`林永来/杨建云`(D23)、`童炳寿/王秀娟`(D30)、`姜蓉兰/洪宗邦`(D34)。
   按客户名取数对这种值**永远取不到**，这 8 个客户会全部漏算。建议**拆成 8 行**，一行一个人。
   （好在这 4 行目前没有金额，只是客户名册，暂时不影响钱。）
2. **E12 写的是「乳铁蛋白」**，而【基础资料】里叫「乳铁」。两边对不上，按产品取数会返回 0。
   要么把 E12 改成「乳铁」，要么去基础资料把「乳铁」改成「乳铁蛋白」。
3. **C45 赵庆仙的生日填成了数字 10**，C23/C34 是「6月17日/3月4日」这种一格两个的文本。
4. **M11 的应付日期是 2020-05-20**，和全表 2026 年的数据对不上，像是模板残留。
5. **【数据录入】第 32 行**：支出类别选了「供应商」，但「供应商」那一列空着，1,000 元认领不到。
