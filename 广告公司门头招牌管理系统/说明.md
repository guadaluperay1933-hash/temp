# 广告公司项目管理系统

把原来散在 22 张表里的东西（940 行日记帐、17 张项目表、两张制作清单、一张综合汇总表）
归到**一个工作簿、12 张表**里。各岗位各管一张录入表，核算表全是公式。

文件：`广告公司项目管理系统.xlsx`

---

## 一、12 张表长什么样

### 录入区 —— 蓝色标签，谁的活谁填

| 表名 | 谁填 | 填什么 |
|---|---|---|
| **项目台账** | 业务 / 下单 | 项目名、客户、合同额、下单日期。做完了填「完工日期」 |
| **订单明细** | 下单 / 设计 | 按件报价的客户（东尼电子那种）逐项登记，自动汇总进项目台账 |
| **采购单** | 采购 | 每一笔材料：供应商、项目、主材/辅材、数量单价 |
| **生产安装** | 设计 / 制作 / 安装 | 设计费、制作工时、安装工时、加班、外叫小工、吊车租车 |
| **资金日记账** | 财务 / 出纳 | 五个账户（支付宝、平安银行、中信银行、微信1、微信2）所有进出 |

### 核算区 —— 绿色标签，全是公式，不用填

| 表名 | 看什么 |
|---|---|
| **账户余额** | 五个账户的即时余额、本月收支、每天跟手机余额对一下 |
| **项目核算** | 一个项目一行：合同额 / 已收 / 未收 / 五项成本 / 毛利 / 毛利率 |
| **利润表** | 按月的收入、成本、毛利、期间费用、净利润，外加在制项目和家底 |
| **供应商对账** | 每家供应商：采购了多少、付了多少、还欠多少 |
| **客户应收** | 每个客户：合同总额、已收、未收 |

另有 **使用说明**（首页，带活的「录入体检」）和 **基础资料**（所有下拉菜单的来源）。

## 二、三条规则

**1. 成本从哪来**

```
项目成本 = 采购单 + 生产安装 + 日记账里选了成本类别的支出
```

三个来源相加。所以同一笔钱只能记在其中**一个**地方。

**2. 别把一笔钱记两次**

- 登过**采购单**的料 → 出纳付钱时，费用类别选 **『付供应商货款』**（它归「往来-货款」，不计成本）
- 没登采购单的**零星开支**（配送费、运费、餐费）→ 出纳直接选成本类别，不用再补采购单

日记账最后一列「核对」会自动查：同一天、同一家、同一个金额，采购单里也有一笔 → 提示
「※这笔可能和采购单重复了」。

**3. 收入按完工确认**

利润表的营业收入 = 当月填了**完工日期**的项目合同额；成本跟着同一个项目走，所以毛利配得上。
没填完工日期的项目算「在制」，不进利润表，在利润表下面的「补充信息」里单独看。

> 长期客户（东尼电子那种一直有小单的）建议**按月建一个项目**：东尼电子26.3、东尼电子26.4……
> 月底填上完工日期就确认那个月的收入。

**账户互转**记两行：转出账户一行支出、转入账户一行收入，费用类别都选『账户互转』，不进利润表。

---

## 三、日记账怎么结出即时余额

五个账户混在一张表里按日期顺着记，第 L 列自动结出**这个账户**当时的余额：

```
本账户余额 = 该账户期初余额 + 从第一行到本行、同一账户的收入合计 − 同样的支出合计
```

第 M 列是全部账户合计。期初余额在【基础资料】A、B 两列填。

## 七、多人同时填要注意的

- 这个文件设计成**一个工作簿多人协作**（WPS 共享 / 金山文档在线表格），
  各人只动自己那张表，互不打架。
- 公式只用了 `SUMIFS / SUMIF / COUNTIFS / VLOOKUP / INDEX / LOOKUP / EOMONTH`，
  **没有用数组公式、没有 FILTER/UNIQUE/XLOOKUP、没有宏**，在线协作文档里都能跑。
- 下拉菜单来自【基础资料】的 18 个定义名称。加客户、加供应商、加人就在那里往下接着写，
  **中间别留空行**（往来单位那一列是靠 COUNTA 接起来的）。
- **灰色格子全是公式，别手动改**。整列到底都有公式，往下填数据就行，不用拖。
- 每张录入表最后一列「核对」会自己挑毛病，红字的去改。
