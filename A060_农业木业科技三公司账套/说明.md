# A060 · 农业基地 / 木业 / 科技 三公司财务账套

一套表装三家公司的账，一年一套。录**购销流水、资金流水、生产加工、其他分录**四张表，
三家的**资产负债表**和**利润表**自己出来，外加一张三家合并报表。

> **这是内账口径**：收入、成本、费用一律按**含税金额**核算，不拆进项销项；
> 税按**实际缴纳**的钱、在缴纳当月直接计入费用，不计提应交税费。

## 一、这套表怎么转

```
             ┌── 购销流水   进货卖货，只管货和票，一律挂应收/应付
录入 4 张 ───┼── 资金流水   所有账户的收支，混排、逐行结出账户余额
             ├── 生产加工   领料 / 加工费 / 产成品入库，按批次归集成本
             └── 其他分录   折旧摊销、计提、结转，一借一贷
                    │
                    ▼  按【记账规则】自动展开借贷
              记账分录（6,900 行容量，不用手工碰）
                    │
                    ▼
              科目余额表（年初 / 期初 / 本期 / 期末，按起止日期）
                    │
     ┌──────────────┼──────────────┬─────────────────┐
     ▼              ▼              ▼                 ▼
 农业资产负债表   木业资产负债表   科技资产负债表    三公司合并报表
 农业利润表       木业利润表       科技利润表       （含内部交易抵销）
```

**不用做记账凭证**。四张录入表填完，借贷两条腿由【记账规则】那张表决定，
看不惯哪条业务的科目走向，就去那张表改那一行，全表立刻跟着变。

**一年一套**：把【参数设置】的会计年度改成新的一年，清掉四张录入表，
把上年期末数抄进【期初余额】，另存一个文件就是新一年的账。

## 三、内账口径：含税核算 + 实交税费

这一版把整套表的口径统一了，三条：

**① 收入、成本、费用全部含税。**
购销流水填的是**实际成交的含税单价**，金额＝数量×单价，进销存和结转成本都是含税数；
资金流水填的是**实际收付的含税金额**。表里再没有「不含税金额」「税额」「价税合计」这些列，
科目表里也删掉了应交税费-进项税额 / 销项税额 / 未交增值税这些明细科目。

**② 税按实际缴纳，缴的当月直接进费用。**
不做「计提应交税费」的分录，资产负债表上也就不再挂应交税费余额。交税这么录：

> 【资金流水】业务类型选「**缴纳税费**」→ 对方科目选「税金及附加」（增值税、附加税、印花税、个税）
> 或「所得税费用」（企业所得税）→ **费用项目选具体税种** → 金额填实际交的钱

**③【税费台账】重做了**：按公司、按月、按税种列实缴数，合计行给出**全年税负率**（实缴税费 ÷ 含税收入）。
示例跑出来：农业 0%、木业 6.42%、科技 12.27%。

顺带的好处：内部交易两边就是同一个含税金额，**卖方开票额 ＝ 买方入账额，一分不差**，
不用再解释「价税合计一致、不含税不一致」那回事。记账分录也从 5 腿/3 腿缩到 **4 腿/2 腿**
（购销：结算 / 收入或存货 / 结转成本借 / 结转成本贷；资金：账户 / 对方），
全表公式从 12.3 万条降到 **10.1 万条**。

## 四、按你之前提的几条做的

### 1）资金流水：混合录入，逐行结出账户余额

一张表按时间顺序往下录，**收进来填「收入金额」、付出去填「支出金额」**，
右边「账户余额」按**账户**逐行滚出来。关联了：

| 关联项 | 在哪一列 | 作用 |
|---|---|---|
| 所属公司 | C | 决定这笔记到哪家公司的账 |
| 账户 | D | 决定余额滚在哪个账号上、对应库存现金还是银行存款 |
| 所属月份 | P（自动） | 税费台账、月度统计按它切 |
| 往来单位 | F | 收付货款自动冲【往来台账】里那家的应收/应付 |
| 费用项目 | H | 进【费用统计】；「缴纳税费」那类在这里选税种 |
| 对方科目 | G | 业务类型里写「@对方」的才要填（缴税、借款、费用归集等） |
| 关联单号 | L | 写对应的购销流水序号，日后核销对单用 |

业务类型决定这笔是收还是付（R 列自动标「收 / 支」），
**填错列会被校验列当场拦下来**：「这类业务是收款，金额填到收入列」。
日期录反了也会提示 —— 余额是按行序滚的。

### 2）几家公司共用几个账号

【资金账户】里按实际开的户登记，「使用公司」写清楚谁在用。示例给了 5 个户：

| 账户 | 类型 | 使用公司 | 期初 |
|---|---|---|---|
| 现金-总部 | 库存现金 | 三家共用 | 10,000 |
| 农商银行-基本户 | 银行存款 | 农业 | 180,000 |
| 工商银行-基本户 | 银行存款 | 木业 | 260,000 |
| 建设银行-基本户 | 银行存款 | 科技 | 320,000 |
| 农商银行-共用户 | 银行存款 | 木业 / 科技 | 0 |

共用户示例：木业收鑫隆建材 30 万、科技收康养电商 24 万都进这个户，
两家又各自从这个户发了工资 —— 账户余额是**这个账号**的真实余额 435,000，
而各家账上的银行存款是**各自的**。
【资金账户】底下有一行**账实对账**把两边加总对上：

> 全部账户余额合计 1,274,240 ＝ 三家「库存现金＋银行存款」科目余额合计 1,274,240　**√ 账实一致**

对不上只有一个原因：有人绕过资金流水直接动了现金/银行（提示语里写了）。

### 3）木业向农户收购原木

往来单位里加了「张德富（农户）」「李长生（农户）」「农户散户（合并登记）」三个。录法：

> 往来单位选农户 → 商品选 MY07 原木 → 发票类型「收购发票」 → 单价填实际收购价

内账含税核算，收购价**全额进原材料成本**，不再拆 9% 进项——能不能抵扣是外账报税的事，
内账只看实际付了多少钱。示例里收了 60 方 × 980 和 45 方 × 1,000，合计 103,800 全进成本。

## 六、几个口径，得说清楚

**存货计价 —— 全年加权平均（含税口径）**
单价 =（期初金额 + 采购入库金额 + 生产入库金额）÷ 对应数量，金额都是含税数。
**分母分子都不含出库**，所以不会循环引用；结转销售成本和生产领用都按这个价。
单价按全精度参与计算、只在显示时留 4 位，所以一个品种全部耗完时结存金额正好是 0，不留几毛钱尾巴。
代价是年中看到的成本是按全年均价倒推的，跟逐笔移动平均会有小差异。

**生产批次成本分摊**
一个批次的「领用投入 + 加工费用」合计，按产出行的权重分摊。
一批两个产出的（示例里 MY-02：模板 + 建筑木方料，权重 3 : 1），
用的是**累计权重法**——最后一条产出自动吸收分位差，
所以批次结转完「生产成本」科目余额正好是 0，不会挂着一分钱。

**内部交易**
三家之间买卖，卖方记多少含税金额、买方就记多少，【内部交易核对】要求**分毫不差**，
差一分就是有一边录错了。合并报表按含税金额抵销内部收入和内部成本。

**税率参数只是参考**
【参数设置】上的附加税率和所得税率不参与任何计算，只是你自己估税时的提醒。
实际交了多少，就在【资金流水】记多少。农林牧渔里的林木种植所得免征企业所得税、
自产农产品销售免征增值税，所以农业基地公司示例里全年税费是 0。

**不要自己做「结转本年利润」**
报表会把损益类自动结进未分配利润（未分配利润 = 年初未分配 + 本年净利润）。
你再手工结一次会重复计算。

**按起止日期筛选**
所有汇总/查询表第 3 行都有「年度 / 起始日期 / 截止日期」：都留空＝全部期间，
只填年度＝整年，填了起止就按起止。**录入表和明细表不筛选，全部显示**。
【进销存台账】是成本基准表，故意不跟着筛选变，要看区间用【收发存查询】。
