## 1. 符号与数据

* 模态 $m\in\mathcal M=\{T,A,V\}$（文本/语音/视觉），特征 $x_m\in\mathbb R^{L_m\times D_m}$，$D_T=768, D_A=74, D_V=35$；
  对齐版 $L_T=L_A=L_V=50$，非对齐版 $L_T=50, L_A=L_V=500$。
* 掩码（`common.data`）：可用 $a_{m,t}=1$ ⇔ 该行特征非零（非有限值先置 0；文本还需在 BERT 注意力掩码内）；
  名义有效范围 $v_{m,t}$ 由 BERT 掩码 / `*_lengths` / 非零包络 + 自动检测的填充方向得到。缺失 = $v\wedge\neg a$。
  **填充、赛题置零、原始天然零行在模型看来一律"不可用"**，不需区分。
* 模态缺失率：$r_m=\dfrac{|\{t: v_{m,t}\wedge\neg a_{m,t}\}|}{|\{t:v_{m,t}\}|}$；可用率 $\rho_m=1-r_m=\dfrac{|\{t:a_{m,t}\wedge v_{m,t}\}|}{\max(1,|\{t:v_{m,t}\}|)}$。
* 标签：强度 $y\in[-3,3]$；极性按题面 $c=\mathbb 1[y>0]\cdot2+\mathbb 1[y=0]\cdot1$（$|y|<10^{-6}$ 视为 0，即 0 Negative / 1 Neutral / 2 Positive）。
  文件自带的 `classification_labels` 不参与训练。

## 2. 预处理

z-score 标准化（`common.data.Normalizer`）：均值/标准差**只用训练集可用位置**逐维计算（std<1e-6 的维取 1），
$\tilde x=\mathrm{clip}\big((x-\mu)/\sigma,\,-10,\,10\big)$，不可用位置保持 0。验证/测试/附件3 用同一组统计量（存于 `model.pt`）。

## 3. 缺失的构造（训练增广与评测协议）

题面缺失 = "若干模态中特征值全为零的随机连续区间"。所有模拟缺失都是在**名义有效范围内**把连续整行置零（drop 掩码），
与附件3 同构。区间放置规则（`common.missing.sample_spans`，有效长度 $n$，缺失率 $r$，段数 $k$，位置 $p$）：

* 总缺失长度 $N_{miss}=\min(\max(\mathrm{round}(r n),1),n)$；$N_{miss}=n$ 时整段缺失；$r\le0$ 时不缺失。
* 段数取 $k'=\max(1,\min(k,N_{miss},n-N_{miss}+1))$（序列太短时实际段数会少于 $k$）。
* 指定位置（$k$ 强制为 1）：head 从起点开始；tail 在终点结束；middle 起点 $\lfloor(n-N_{miss})/2\rfloor$。
* 随机位置：各段长度为 $N_{miss}$ 的均匀随机正整数拆分（每段 ≥1）；剩余 $n-N_{miss}$ 个位置作为 $k'+1$ 个间隙随机拆分，
  内部间隙至少 1（各段不相邻、不重叠）。

**3.1 训练增广**（`AugmentConfig` + `random_drop_for_sample`，每条样本、每个 epoch 用 `default_rng((seed, epoch, i))` 独立抽样）：

| 参数 | 值 | 含义 |
|---|---|---|
| p_sample | 0.8 | 样本施加缺失的概率（其余 20% 缺失视图 = 完整视图） |
| p_modality | 0.5 | 每个模态被选中的概率；一个都没选中时均匀选 1 个 |
| p_full_drop | 0.1 | 被选模态整段缺失（$r=1$）的概率 |
| ratio_range | [0.05, 0.9] | 否则 $r\sim U(0.05,0.9)$ |
| max_spans | 3 | 段数 $k\sim U\{1,2,3\}$，随机位置 |
| keep_one_intact | false | 允许三模态同时受损 |

**3.2 固定混合缺失协议（仿附件3）**：每条样本各模态以 0.5 概率被选中（至少一个），$r\sim U(0.1,0.7)$，$k\sim U\{1,2\}$，
随机位置，无整段缺失；按样本顺序用 `default_rng(seed)` 生成。验证集 seed=2026（早停、选种子、调阈值），测试集 seed=2027（消融表、错误归因）。
缺失规律实验中的"混合协议"另用 3 个种子 {2027, 2028, 2029} 取平均。

**3.3 评测协议**（`common.missing.protocol_spec(combo, r, position, k)` + `make_drop_masks(seed)`）：
combo ∈ {T, A, V, TA, TV, AV, TAV}，combo 中每个模态独立按 3 节规则放置区间。
掩码只由（划分的名义有效范围、协议参数、种子）决定；**每个评测条件先生成一次掩码，再依次喂给所有模型**，因此所有模型面对完全相同的缺失。

## 4. 网络结构

训练时每个 batch 构造两个视图：完整视图 $X$（仅数据自带的不可用位置）与缺失视图 $\tilde X$（再按 drop 掩码置零，
$\tilde a=a\wedge\neg\mathrm{drop}$），两次前向**共享全部参数**。评测时模型只看到（施加了评测掩码的）一个视图。

**4.0 长序列时间下采样（对原设计的改进，只影响非对齐版本）**：模态 $m$ 的存储长度 $L_m>P_{max}=100$ 时，
步长 $s_m=\lceil L_m/P_{max}\rceil$（非对齐版语音/视觉 $500\to100$，$s=5$；文本与对齐版 $s=1$，不做任何处理）。
第 $j$ 个窗口 $W_j=\{js,\dots,js+s-1\}$：
$$\bar x_{m,j}=\frac{\sum_{t\in W_j}a_{m,t}v_{m,t}\,\tilde x_{m,t}}{\max(1,\sum_{t\in W_j}a_{m,t}v_{m,t})},\qquad
\bar a_{m,j}=\bigvee_{t\in W_j}(a_{m,t}\wedge v_{m,t}),\qquad \bar v_{m,j}=\bigvee_{t\in W_j}v_{m,t}.$$
即窗口内只要有可用行就用可用行的均值（部分缺失的窗口相当于做了局部插补），整窗缺失才记为缺失。
原因：非对齐版语音/视觉有效长度可达数百，编码器与跨模态注意力代价随 $L^2$ 增长，在 CPU 上单轮训练慢约 10 倍（合成数据实测 175 s → 17 s/epoch）。
步长解析后写入配置 `model.temporal_stride` 并存进 `model.pt`，推理时一致。下文 4.1–4.3 中的 $x,a,v$ 均指下采样后的序列。

**4.1 单模态编码器**（`common.layers.ModalityEncoder`，每个模态一个，$d=128$）：

$$u_t=\mathrm{LN}(W_m\,\mathrm{Dropout}_{0.1}(\tilde x_{m,t})),\quad
h^{(0)}_t=\big(a_t\,u_t+(1-a_t)\,e_{\mathrm{MISS}}\big)v_t+\mathrm{TE}(\tau_t,k_t)\,v_t,$$
$$h^{(1)}=h^{(0)}+\mathrm{Conv1d}_{k=3}(h^{(0)})\odot v,\qquad H_m=\mathrm{LN}\big(\mathrm{Transformer}_2(h^{(1)};\ \text{key mask}=\neg a)\big)\odot v .$$

* $e_{\mathrm{MISS}}$ 为可学习 [MISS] 向量：缺失位置只作为 query 从**可用位置**取信息（key_padding_mask = ¬avail），
  自身从不作为 key/value —— 置零区间不会被当成"零特征证据"传播（模态内插补）。整行不可用时放开第 0 位避免 NaN。
* 时间编码 $\mathrm{TE}(\tau,k)=[\sin(100\tau\omega_j),\cos(100\tau\omega_j)]_j\ \Vert\ [\sin(k\omega_j),\cos(k\omega_j)]_j$，
  $\omega_j=10000^{-2j/(d/2)}$，$j=0..d/4-1$；$\tau\in[0,1]$ 为有效范围内相对时间，$k$ 为有效范围内序号。
* Transformer：2 层 pre-LN，4 头，FFN 256（ReLU），dropout 0.2。

**4.2 跨模态重构**（`q2/model.py: CrossModalReconstruction`，模态数 ≥2 时启用）：对模态 $m$，其余模态 $o\neq m$，

$$Q=\mathrm{LN}^q_m(H_m)+P(\tau_m),\quad K=[\,n^k_m;\ \mathrm{LN}^k_m(H_o)+P(\tau_o)\,]_{o\ne m},\quad V=[\,n^v_m;\ H_o\,]_{o\ne m},$$
$$\hat H_m=\mathrm{Dropout}_{0.2}\big(\mathrm{MHA}_m(Q,K,V;\ \text{key mask}=[0;\neg a_o])\big),$$
$$g=\sigma\big(W^g_m[H_m;\hat H_m;\mathbb 1^{miss}_m]+b^g_m\big),\qquad H'_m=(H_m+g\odot\hat H_m)\odot v_m .$$

* $P(\tau)=W_P\,\mathrm{TE}(\tau,0)$：只用相对时间 $\tau$（非对齐版本三模态的序号不可比），让非对齐序列在时间上可比；
* 只以其余模态的**可用**位置为 key；$n^k_m,n^v_m$ 是可学习的 null 槽位（永不屏蔽，$n^v$ 初始化为 0）——
  其余模态整段不可用时注意力可以"什么也不取"（**对原设计的改进**：否则会被迫读到填充位置的零向量）；
* $\mathbb 1^{miss}_{m,t}=v_{m,t}\wedge\neg a_{m,t}$，门控让缺失位置更多地依赖跨模态上下文；MHA 4 头，注意力 dropout 0.2。
* 重构头 $\hat x_m=W^{rec}_m H'_m\in\mathbb R^{L_m\times D_m}$（仅训练时用于 $\mathcal L_{rec}$）。

**4.3 池化与可用率**：$\alpha^{time}_{m,t}=\mathrm{softmax}_{t:v_t}\big(w^\top\tanh(W h'_t)\big)$，
$z_m=\sum_t\alpha^{time}_{m,t}H'_{m,t}$（`MaskedAttentionPool`，对名义有效位置池化——缺失位置此时已含插补内容）；
$\rho_m$ 见第 1 节，**在下采样之前的原始分辨率上计算**（否则部分缺失的窗口会被算作可用而高估 $\rho$）。

**4.4 可靠性门控融合**：

$$s_m=w_{2,m}^\top\,\mathrm{GELU}(W_{1,m}[z_m;\rho_m]+b_{1,m})+b_{2,m}\ (\text{隐层 }64),\qquad \alpha=\mathrm{softmax}_m(s_m),$$
$$t_m=z_m+e_m+W_\rho\,\rho_m,\qquad c=\mathrm{LN}\big(\mathrm{Transformer}_1([\mathrm{CLS};t_T;t_A;t_V])_{\mathrm{CLS}}\big),\qquad h=c+\sum_m\alpha_m z_m .$$

融合 Transformer：1 层 pre-LN，4 头，FFN 256（ReLU），dropout 0.2；$e_m$ 模态嵌入，$W_\rho\in\mathbb R^{d\times1}$。

**4.5 输出头**：$f=\mathrm{Dropout}_{0.2}(\mathrm{GELU}(W_f h+b_f))$（128 维），$\hat y=3\tanh(w_r^\top f+b_r)$，$\ell=W_c f+b_c\in\mathbb R^3$。

参数量：完整 MRG-Net 1,712,055；w/o 重构 1,282,890；单模态 T/A/V 588,614 / 499,782 / 494,790；晚期融合基线 145,924
（对齐/非对齐相同，与序列长度无关）。

## 5. 目标函数

$$\mathcal L=\sum_{\text{视图 }X,\tilde X}\Big[\mathcal L_1(\hat y,y)+\lambda_{cls}\,\mathrm{CE}_w(\ell,c)\Big]+\lambda_{rec}\mathcal L_{rec}+\lambda_{kd}\mathcal L_{kd},
\qquad \lambda_{cls}=0.5,\ \lambda_{rec}=0.1,\ \lambda_{kd}=0.5 .$$

* $\mathcal L_1$：batch 平均绝对误差。
* 类别加权交叉熵：$\mathrm{CE}_w=\dfrac{\sum_i w_{c_i}\,\mathrm{CE}_i}{\sum_i w_{c_i}}$（PyTorch `weight=` 的均值约定），
  $w_c\propto n_c^{-1/2}$（$n_c$ 为训练集类别计数），再归一化使 $\sum_c \frac{n_c}{N}w_c=1$。
* 重构损失（只在"完整视图可用、缺失视图不可用"的位置 $\mathcal P_m=\{(i,t):a^{X}_{m,i,t}\wedge\neg a^{\tilde X}_{m,i,t}\wedge v_{m,i,t}\}$，
  即原本可用、被增广置零的位置（步长 >1 时为整窗被置零的窗口）；目标 $\tilde x$ 是完整视图（下采样后）的标准化特征）：
  $$\mathcal L_{rec}=\frac1{|\mathcal M'|}\sum_{m\in\mathcal M'}\frac{1}{|\mathcal P_m|D_m}\sum_{(i,t)\in\mathcal P_m}\lVert\hat x_{m,i,t}-\tilde x_{m,i,t}\rVert_2^2,$$
  $\mathcal M'$ 为本 batch 中 $\mathcal P_m\ne\emptyset$ 的模态。
* 一致性蒸馏（教师 = 同一网络在完整视图上的输出，stop-gradient；学生 = 缺失视图；只对本 batch 中至少有一个"原本可用的位置被增广置零"
  的样本集合 $S=\{i:\exists m,t:\ \mathrm{drop}_{m,i,t}\wedge a_{m,i,t}\wedge v_{m,i,t}\}$，按原始分辨率判断）：
  $$\mathcal L_{kd}=\frac{1}{|S|\,d}\sum_{i\in S}\lVert\tilde h_i-\mathrm{sg}(h_i)\rVert_2^2+T^2\cdot\frac1{|S|}\sum_{i\in S}\mathrm{KL}\big(\mathrm{softmax}(\mathrm{sg}(\ell_i)/T)\,\Vert\,\mathrm{softmax}(\tilde\ell_i/T)\big),\quad T=2 .$$
* 关闭增广（w/o aug、晚期融合）时只有完整视图一项，$\mathcal L_{rec}=\mathcal L_{kd}=0$。

## 6. 训练方案

| 项 | 值 |
|---|---|
| 优化器 | AdamW，lr $3\times10^{-4}$，weight decay $10^{-2}$ |
| batch | 64（训练集打乱，DataLoader 生成器以种子固定） |
| 轮数 | ≤40，早停 patience 8（验证分连续 8 轮不升即停），恢复最佳轮参数 |
| 学习率调度 | 余弦退火（按 step），前 1 个 epoch 线性 warmup：$\eta_s=\eta_0\cdot s/S_w$（$s<S_w$），否则 $\tfrac{\eta_0}{2}(1+\cos(\pi\frac{s-S_w}{S-S_w}))$；可选 plateau（×0.5，patience 3） |
| 梯度裁剪 | 全局 L2 范数 1.0 |
| 验证分（早停/选模型） | $\tfrac12[\mathrm{comp}(\text{完整验证集})+\mathrm{comp}(\text{混合协议验证集, seed 2026})]$，$\mathrm{comp}=F1_w+Acc_3+r-\mathrm{MAE}$；这里分类用 $\arg\max\ell$（不加偏置），强度用 $\mathrm{clip}(\hat y,-3,3)$ |
| 种子 | 主模型 {1,2,3}，报告 mean ± std（样本标准差，ddof=1）；**最终模型 = 验证分最高的种子** |
| 消融/基线种子 | {1}（算力允许可设 `ablation.seeds: [1,2,3]`） |

所有随机性由种子控制：`set_seed(seed)`（python/numpy/torch）、增广 `default_rng((seed,epoch,i))`、评测掩码固定种子。

## 7. 决策层（验证集上选阈值）

* 极性：$\hat c=\arg\max_k(\ell_k+b_k)$，$b=(0,\beta,0)$；$\beta$ 在**验证集混合缺失协议（seed 2026）**的 logits 上网格搜索
  $\beta\in\mathrm{linspace}(-2,2,41)$ 使加权 F1 最大，并列时取 $|\beta|$ 最小者（`common.decision.tune_neutral_bias`）。每个模型（变体×种子）各调各的。
* 强度一致性投影（`project_intensity`，先 clip 到 [-3,3]）：Negative → $\min(\hat y,-0.01)$；Neutral → 0；Positive → $\max(\hat y,0.01)$。
* 报告"投影前"（分类头 + 原始回归）与"投影后"（自洽输出）两套指标（`evaluate_decisions`）；对外 CSV 用投影后结果，原始回归另列 `raw_intensity`。
* 附件3 概率列 $p=\mathrm{softmax}(\ell+b)$，保证 $\arg\max p=\hat c$。

## 8. 消融与基线（同一数据、同一超参数，仅改动所列部分）

| 变体 | 改动 | 说明 |
|---|---|---|
| full | — | MRG-Net 完整模型 |
| no_aug | `augment.enabled=false` | 只用完整数据训练（单视图，无重构/蒸馏损失） |
| no_rec | `model.use_reconstruction=false` | 去掉跨模态重构模块与 $\mathcal L_{rec}$（$H'_m=H_m$） |
| no_kd | `loss.lambda_kd=0` | 仍双视图监督，但无一致性蒸馏 |
| no_gate | `model.use_gate=false` | $\alpha_m\equiv1/3$（融合 token 中的 $\rho$ 嵌入保留） |
| late_fusion | 晚期融合结构 + 无增广 | 各模态在可用位置上对标准化特征取均值 → 拼接(877 维) → Dropout 0.1 → Linear 128 → GELU → Dropout 0.2 → Linear 128 → GELU → 输出头 |
| naive_impute | 测试时插补 + no_aug 模型 | 缺失位置 $t$ 用同模态前后最近可用行线性插值 $x_t=(1-w)x_l+wx_r$，$w=\frac{t-l}{r-l}$；只一侧可用时取最近行；插补行视为可用；偏置在插补后的验证集混合协议上重调 |
| uni_text / uni_audio / uni_vision | `model.modalities=[m]` | 单模态 MRG-Net（其余模态训练、测试都完全不输入；自动无跨模态重构；α≡1），同样的增广 |

`ablation.csv`：每个变体 × {valid, test} × {complete, mixed} × {projected, raw}，指标为种子均值，主指标带 `_std`。

## 9. 缺失规律实验（附件2 测试集，另在验证集重复）

模型：full、no_aug、naive_impute、no_rec、no_kd、no_gate、late_fusion（各取选中种子），所有模型同一掩码。
指标：Acc3、F1_w、F1_macro、MAE、Corr（投影后）+ `mae_raw`、`corr_raw`（投影前）+ acc2/acc7；
MRG-Net 类模型另记平均门控权重 `alpha_*` 与平均可用率 `rho_*`；`miss_T/A/V` 为该条件下实际平均缺失率（含天然零行）。

1. **类型×缺失率** `missing_type_ratio.csv`：combo ∈ {T,A,V,TA,TV,AV,TAV} × $r\in\{0,0.1,\dots,1.0\}$，单段、随机位置，
   掩码种子 {11,12,13} 取平均（另有逐种子 `*_by_seed.csv`，均值文件带 `*_std` 与 `n_mask_seeds`）。$r=0$ 即完整输入。
2. **缺失位置** `missing_position.csv`：combo ∈ {T,A,V,TAV} × $r\in\{0.2,0.4\}$ × {head, middle, tail}，单段（位置确定，与种子无关）。
3. **缺失时长/碎片化** `missing_fragmentation.csv`：combo ∈ {T,A,V,TAV} × 总缺失率 $r\in\{0.3,0.6\}$ × 段数 $k\in\{1,2,3,5\}$，
   随机位置，3 个掩码种子平均；`n_spans_actual` 为受损样本的实际平均段数（短序列放不下 5 段）。
4. **混合协议** `missing_mixed.csv`：3.2 节协议，种子 {2027,2028,2029}。

**退化律拟合** `degradation_fit.json`（每个 模型×划分×combo）：

* 幂律：$\Delta\mathrm{MAE}(r)=\mathrm{MAE}(r)-\mathrm{MAE}(0)=\beta r^{\gamma}$，只用 $r>0$ 的点；初值由 $\Delta>0$ 点上 $\log\Delta=\log\beta+\gamma\log r$ 的线性回归给出，
  再用 `scipy.optimize.curve_fit` 非线性最小二乘（约束 $\beta\ge0$，$0.05\le\gamma\le10$）；报告 $\beta,\gamma,R^2$。对 `mae`（投影后）与 `mae_raw` 各拟合一次。
* 线性灵敏度：$M(r)\approx a+b\,r$ 的最小二乘斜率 $b$ 与 $R^2$（$M$ ∈ Acc3, F1_w, F1_macro, Corr, MAE）。
* 相对退化：$(M(r)-M(0))/|M(0)|$；曲线下面积 $\int_0^1M(r)dr$（梯形法）。
* 汇总：各 combo 在 $r=1$ 时的 ΔMAE 排序（哪类模态缺失伤害最大）、ΔF1；位置效应（每个 combo@r 的最差位置、MAE 极差）；
  碎片化效应（MAE、F1 对段数的线性斜率）。

## 11. 附件3 推理

`python -m q2.predict --run <run> --input <附件3.pkl> --split auto`：`auto` = 文件只有一个划分（或直接是字段字典）就用它，多划分时优先 `test`。
附件3 的缺失本身就是名义有效范围内的全零行，读入后自动成为不可用位置；文件版本与模型版本不一致时报错。

`附件3_预测结果.csv`（UTF-8-SIG）列依次为：

| 列 | 含义 |
|---|---|
| index | 样本在文件中的序号（从 0 起） |
| id / video_id / clip_id | 原始 id 与按 `$_$` 拆分的两部分 |
| pred_polarity / pred_polarity_cn / pred_class | Negative/Neutral/Positive、负向/中性/正向、0/1/2 |
| pred_intensity | 一致性投影后的强度（4 位小数），与极性自洽 |
| raw_intensity | 回归头原始输出（clip 到 [-3,3]） |
| prob_negative / prob_neutral / prob_positive | $\mathrm{softmax}(\ell+b)$ |
| miss_ratio_text / audio / vision | 检测到的缺失率（有效范围内全零行占比，`common.missing.missing_statistics`） |
| missing_modalities | 缺失率>0 的模态组合，如 `T+A`；无缺失为 `none` |

`附件3_summary.json`：类别计数/占比、强度统计与直方图、平均概率、各模态缺失统计（有缺失样本数、缺失率分布与直方图、段数分布、
位置分布——按缺失中心相对位置三等分为 head/middle/tail）、缺失组合频次、各组合下的预测构成、自洽性核查结果。
另有 `附件3_缺失检测明细.csv`（逐样本×模态的区间）与图 `att3_missing_ratio_hist.png`、`att3_pred_distribution.png`、`att3_by_combo.png`。
注意：检测到的"缺失"包含原始数据中的天然零行（如视觉未检出人脸），无法与人为置零区分——论文中应如实说明。
