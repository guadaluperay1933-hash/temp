# 论文写作要点（给写 paper/论文.md 的人）

## 1. 版式与生成方式

- 正文写在 `paper/论文.md`（Markdown + LaTeX 公式），由 `python -m paper.build_paper` 渲染成 Word（公式为 Word 原生公式）。
- 数值、表格、图片一律用占位符从运行结果引用（语法见 `paper/build_paper.py` 顶部说明）：
  `{{q2.metrics_test.xxx|pct2}}`、` ```table ... ``` `、`![图 n  标题](fig:q2/figures/xxx.png){width=90%}`。
  需要"最差缺失类型是哪个""退化指数是多少"这类派生量，写进 `paper/derived.py` 的 `compute(ctx, run_dirs)`，正文用 `{{derived.xxx}}`。
- **绝不手写实验数值**：真实附件还没跑，任何数字都必须来自占位符；合成数据的数值不得出现在正文。
  需要定性结论（"视觉缺失影响最小"）的地方，用 derived 派生出的文字（如 `{{derived.q2_least_harmful_combo_cn}}`）或写成条件句，保证换成真实结果后依然成立。
- 标题层级：`#` 一级（一、问题重述 …），`##` 二级（1.1 …），`###` 三级。编号手写在标题文字里。
- 图题写在图片 alt 里（"图 n  标题"），表题写在 table 块的 caption（"表 n  标题"），编号全篇连续。
- 公式：行间公式用 `$$ … \qquad (n) $$` 手动编号；绝对值 `\left| x \right|`、范数 `\left\| x \right\|` 均可（Word 渲染正常）。
- 研赛格式：不出现任何参赛单位、队员姓名、队伍编号；摘要约 1 页，写清三问各自的方法、关键结果（占位符）与结论；关键词 4–6 个。

## 2. 问题分析（核心思路，正文"二、问题分析"据此展开）

**总体**：三问是逐层递进的三层任务——数据层（问题1：把原始视频变成可建模、可核验的时序特征）、鲁棒层（问题2：输入不完整时仍稳定预测）、
可信层（问题3：预测的同时给出可量化、可复核的依据）。问题1 确立的"序列位置 ↔ 原始时间"的对应关系，也是问题3 把关键证据回看到原始视频的基础。

**问题1**：三模态在采样频率（文本以词为单位、语音 100 Hz 帧、视频 25–30 fps）、特征维度（768/74/35）和时间尺度上都不同。
以"词级强制对齐得到的时间区间"为锚：对齐版本把语音帧、视频帧按词区间聚合到文本的 token 位置上；非对齐版本则把语音、视觉放到统一的
固定时间栅格（80 ms）上，保留各自独立的时序。题目对特征文件提出三条硬要求（覆盖完整性、时序可核验性、方法可复现性），
每一条都要落到具体的文件与检查项上（manifest、逐位置对齐记录、verify 报告、run_info）。

**问题2**：局部缺失 = 某模态一段连续位置整行为零。难点：(1) 零向量不是"没有信息"而是"错误信息"，直接喂给常规融合模型会把零当作真实特征；
(2) 缺失的类型（哪几个模态）、位置（开头/中间/结尾）、时长（缺失率、是否碎片化）都会影响性能，需要系统刻画；
(3) 要在不知道测试缺失模式的前提下学到对各种缺失都稳健的表示。
对策：把全零行识别为缺失并在注意力中屏蔽 → 模态内上下文补全 + 跨模态重构 → 按"可用比例 + 表示质量"动态分配模态权重 →
训练时随机施加与附件3 同构的连续区间缺失，并用"完整视图 → 缺失视图"的一致性蒸馏把完整输入时学到的判别能力迁移过来。
影响规律用受控实验得到：固定种子的缺失掩码，按"类型 × 缺失率""位置""碎片化"三个因素分别扫描，并对退化曲线拟合经验规律（幂律/线性斜率）。

**问题3**：题目要求的可解释性有三层：模态间作用差异（各模态作用程度、主要参考模态）、模态内关键证据（局部片段）、可回看到原始素材。
"可量化、可复核"意味着：解释量要有明确数学定义、能由他人重新计算，并且要检验解释是否忠实于模型（而不是看起来合理）。
对策：模型结构上做可加分解（模态专家 + 交互专家 + 门控），每个专家内部用"注意力 × 位置值"的形式，使预测可以精确分解到模态、再分解到位置；
模态作用程度用三人合作博弈的精确 Shapley 值（8 次前向即可精确计算，满足有效性公理 Σφ = f(全) − f(空)）；
关键证据取贡献最大的位置并合并为连续片段，映射到词、语音时段、视频关键帧；再用积分梯度一致性、删除/保留检验（comprehensiveness / sufficiency）验证忠实性。

## 3. 模型假设（正文"三、模型假设"）

1. 附件2 各划分及附件3、附件4 的特征由同一流程提取，除人为置零的缺失外同分布。
2. 附件3 中名义有效范围内"整行为零"的连续区间即为缺失区间；原始特征中天然为零的行（如未检出人脸）同样视为不可用信息。
3. 缺失的发生与样本的情感内容无关（完全随机缺失，MCAR），因此可以在完整样本上随机施加缺失来模拟。
4. 情感强度标注是多名标注者评分的平均，含有标注噪声；强度为 0 的样本属于中性，且只属于中性。
5. 对齐版本中同一位置的三模态特征对应同一词级时间区间；非对齐版本中语音、视觉特征沿时间近似等间隔排列（在附件4 上由数据检验，见问题3）。
6. 问题1 中赛题提供的转写文本是准确的；强制对齐的时间误差在词级范围内，可以接受。

## 4. 章节结构（建议）

摘要（含关键词）→ 一、问题重述 → 二、问题分析（含总体技术路线图，可用文字框图）→ 三、模型假设 → 四、符号说明（表）→
五、问题1（数据与预处理；三模态特征定义与提取；时序对齐模型；特征文件规范与读取；全量结果汇总表；典型样本验证；可复现性说明）→
六、问题2（缺失的形式化；MRG-Net 结构；目标函数；训练方案与参数；验证集基础性能；缺失类型/缺失率/位置/时长影响规律；消融实验；附件3 预测结果；错误归因）→
七、问题3（可解释性的定义与量化；AMEE 结构；目标函数；训练；性能及可解释性代价；解释卡；局部片段重要性与三模态作用差异；忠实性检验；附件4 结果汇总；错误归因）→
八、模型评价与推广（优点、不足、改进方向）→ 参考文献 → 附录（代码与文件清单、运行说明、全量结果表）。
